## 0. 計画を変えた理由（群の比較 → 順位相関）

10/08 の合意は「低ランク群（アイアン1〜シルバー3）と高ランク群（アセンダント1以上）を各10名で比べる」だった。
2026-11-09 時点の応募者は5名で、集まっても合計10名程度の見込み。しかもゴールド〜ダイヤモンド（`mid`）はどちらの群にも入らない。

並べ替え検定では、**どんなに差がはっきりしていても p 値はある値より小さくならない**（各群の人数だけで決まる。一方の群の全員が他方の全員より大きいときが下限）：

| 各群の人数 | p 値の下限（両側） |
|---|---|
| 3 vs 3 | 0.100 |
| 4 vs 4 | 0.029 |
| 5 vs 5 | 0.008 |

主要比較を6つにして Holm で補正すると、一番厳しい基準は 0.05 ÷ 6 ≒ 0.0083。各群4名以下では、**データを見る前から「有意差なし」が確定する**。
そこで、`mid` を含む全員を使い、ランクを順位として Gaze % との順位相関を調べる（案Y）。

- 変えた理由は**人数の見込み**であり、結果ではない（本実験のデータは未取得、予備実験は群の比較をしていない）
- 題目「熟練度の**関係**」とも一致する
- ~~群の比較（low / high）は記述的な結果として残す（§7）~~ → **2026-11-17 に変更**：群ごとの要約（中央値・四分位範囲・人数）は出さない。群は散布図の点の色と、群×ロールの人数の表にだけ使う（§7。理由：群は1〜2名になりうる）
- 2026-11-16 以降は、順位相関にも**検定をしない**（§4b）。上の表は「群の比較をやめた理由」として残す。順位相関にした理由のうち「`mid` を含めて全員を使える」は今も有効
- 倫理審査の書類に分析方法（群の比較）を書いていた場合は、変更の届けが要るか教授に確認する

## 1. 対象者と除外

- 対象：本実験（アンレート）の参加者全員。**`mid` も含める**。未ランク者は除外（10/08 の合意どおり、ランクの値が無いため）
- 除外は `aggregate_sessions.py` の `qc_report.csv` で**機械的に**決める（その場の判断で足したり減らしたりしない）。基準は CLAUDE.md §2 の「除外基準」：
  - 区間内の有効率 ≥ 0.7
  - 同期が confirmed_based かつ期待範囲内
  - 較正が合格（不合格の人は感度分析でのみ使う）
  - 解像度が一致
  - 実測の眼−画面距離と基準 650 mm の差 ≤ 100 mm
  - **区間の coverage ≥ 0.9**（2026-11-09 決定）
  - **分析時間の下限は設けない**（2026-11-09 決定。§1a）
- **除外はセッション（試合）単位**（2026-11-10 決定）。上の基準はセッションごとに判定し、除外候補（`qc_report.csv` の `exclude_candidate`）のセッションを抜いてから参加者単位でサンプル数・時間を足す（`participant_aoi_metrics.csv` の `session_set: excluding_flagged`。`aggregate_sessions.py` の既存の動作）
  - 2試合した人（降参）は、残ったセッションだけで主解析に入れる。分析時間の下限は設けないので、1試合分だけ残った人も含める
  - すべてのセッションが除外候補になった人は、主解析から外れる
  - 理由：基準（同期・較正・有効率など）はどれもセッションの記録の品質を見ている。1試合の記録の不具合で、問題のない別の試合まで捨てる理由がない
  - 明文化のきっかけ：S01（11/10）の1試合目が同期の期待範囲外（confirmed 45.0 ms、LAB_CHECKLIST 4b）。コードの動作は以前からセッション単位で、それを計画に書いただけ（S01 の集計結果を見る前）
- 除外の理由と人数を、応募 → 参加 → 除外 → 解析の流れの図にして報告する。**参加者の数とセッションの数の両方**を書く（2試合した人のうち1試合だけ除外した人がいるため）
- **データ品質の示し方**（2026-11-17 決定）：データ品質は**1セッション1行**で示す。図と表はすべて同じ `qc_report.csv` から作る
  - 本文：(1) **数だけの流れの図**（参加者とセッションの両方。除外の箱は件数と、下の表への参照だけを書く）、(2) **除外した人とセッションだけの表**（理由・当てはまった基準・感度分析で戻すか）、(3) 主解析に使ったセッションの解釈用の表（§7d）
  - 付録：**全セッションの判定用の数値**（区間内の有効率・coverage・同期・較正・眼−画面距離）
- 予備実験の参加者（PL01〜PL03、実験者本人）は本解析に入れない

### 1a. 分析時間の下限を設けない理由
- 人数が少なく、1人除外するごとの損失が大きい
- 分析時間の短い人を外すと、早く死ぬ人（＝ランクと関係しうる）を選んで外すことになり、偏りが入りうる
- アンレートは最短でも13ラウンドあり、降参で終わったときはもう1試合する（11/05 決定）ので、極端に短いデータは出にくい
- その代わり、**参加者ごとの分析時間（秒）を結果の表に必ず載せる**。分析時間が短い人の値は、小さい AOI ほど偶然の影響を受けやすいことを限界に書く

## 4. ランクとの順位相関（案Y）

### 4a. ランクを数にする
- 使うのは **`rank_current`**（台帳。11/06 の group との照合と同じ）。`rank_peak` を使った場合は感度分析（§6）
- 段位とディビジョンから順番の数を作る：アイアン1 = 1、アイアン2 = 2、…、イモータル3 = 24、レディアント = 25
  - 例：シルバー2 = 8、ゴールド1 = 10、アセンダント1 = 19
- 順位相関は**順番しか使わない**ので、「アイアンとブロンズの差」と「ダイヤとアセンダントの差」が同じ幅かどうかは結果に影響しない
- 同じランクの人がいたら、同順位（平均順位）として扱う

### 4b. 報告するもの：ρ と向き（検定はしない。2026-11-16 決定）
- **Spearman の順位相関係数 ρ**（ランクの数と、AOI 別 Gaze % の順位の相関）と、その**向き**（正：ランクが高いほど多く見る／負：少なく見る／0：向きなし）
- **検定（並べ替え検定・Holm 補正）はしない**。人数にかかわらず、主指標・副指標とも ρ と向きだけを報告する
  - 理由：6名でも Holm の最初の基準（0.05/6 ≒ 0.0083）は ρ = ±1 でしか満たせず、補正なしの 0.05 でも |ρ| ≥ 0.886 が必要（全数を数えて確認）。
    並べ替えの p は |ρ| と人数で決まり、ρ 以上の情報を持たない
  - 経緯：2026-11-09 は並べ替え検定（100,000 回、p = (k + 1)/(100,000 + 1)、シード固定）＋ Holm の計画だった。
    2026-11-15 に「5名以下は検定しない、6名以上は p を参考として付ける」に変え、2026-11-16 に検定そのものをやめた（変更履歴）
- 同じランクの人がいたら同順位（平均順位）として ρ を計算する（§4a）

### 4c. 不確かさの示し方（2026-11-17 決定。信頼区間はやめた）
- **95% 信頼区間は出さない**。不確かさは、全数を数えた「関係がなくても、その人数で |ρ| ≥ 0.5 になる並べ方の割合」で示す（同順位が無い場合）：

  | 人数 | 関係がなくても \|ρ\| ≥ 0.5 になる並べ方の割合 |
  |---|---|
  | 3 | 100%（6通り中6通り） |
  | 4 | 42%（24通り中10通り） |
  | 5 | 45%（120通り中54通り） |
  | 6 | 30%（720通り中214通り） |

- この割合は**比較ごとには計算せず、人数ごとに一度だけ方法と限界の節に書く**。比較ごとに「今回の |ρ| 以上になる割合」を出すと、両側の並べ替え p 値と同じものになるため（§4b で検定をやめた理由と矛盾する）
- 経緯：当初（2026-11-09）は、Fisher の z 変換と Spearman 用の標準誤差 √((1 + ρ²/2)/(n − 3))（Bonett & Wright, 2000）で 95% 信頼区間を報告する計画だった。
  参加者が想定（10名程度。§4d の表は8〜12名）より少なく、近似の前提が成り立たないため、全数を数えた値に替えた。標準誤差の出典（Bonett & Wright, 2000）は未入手のまま

### 4d. 検定しない理由：この人数で何が検出できたか（データを見る前の目安。2026-11-09 の表を残す）
並べ替え検定で「有意」になるために必要な |ρ| の大きさ（同順位が無い場合のシミュレーション）：

| 人数 | 基準 0.05 | 旧・主要比較（6つ）の Holm で一番厳しい基準 0.0083 |
|---|---|---|
| 8 | 0.71 | 0.86 |
| 10 | 0.64 | 0.79 |
| 12 | 0.58 | 0.73 |

- 8名以上の見込みでも、かなり強い関係でないと有意にならなかった。実際の人数はこれより少なく、p 値の下限は4名で 2/24 ≒ 0.083、5名で 2/120 ≒ 0.017、
  6名でも Holm の基準 0.0083 を満たすのは ρ = ±1 だけ。これが検定をやめた理由（§4b）
- 同じランクの人が多い、または全員が狭い範囲のランクに集まると、ρ はさらに不安定になる（ランクの範囲が狭いことを限界に書く）

### 4e. この方法の限界（方法・限界の章に書く）
- **単調な関係**（ランクが上がるほど一方向に増える・減る）しか検出できない。中位のランクだけが多く見る、のような山形の関係は検出できない → 一人ひとりの点の図（§7）で確認する
- 相関であって因果ではない。ランクは、プレイ時間・年齢・使うロールなどと一緒に動く
- ランクは act ごとに変わり、`rank_current` はその時点の値
- 人数が少なく、1人の値で ρ の大きさが大きく変わる（§6 で1人抜き分析をしない理由。散布図と範囲で示す）

### 4f. 本文で取り上げる比較と書き方（2026-11-17 決定）
- **関係の有無を判定する基準は置かない**（|ρ| の閾値も、p 値も使わない）
  - 理由：関係がなくても 4名 42%・5名 45%・6名 30% の並べ方で |ρ| ≥ 0.5 になる（§4c）
- **本文で取り上げる比較**：
  - Furukado & Hagiwara (2023) の著者が熟練度による違いとして解釈した AOI（III.A、p. 109）に当たる **下部HUDまとめ・crosshair・minimap**
  - **下部HUDの内訳の比較3つ**（health_armor・abilities・ammo_weapon）。毎回3つとも示す（都合のよいものだけを選ばない）
  - minimap を入れる理由：同論文で有意差はない（p = .063、Table 2、p. 109）が、著者は III.A（p. 109）で効果量が大きいと述べたうえで、熟練群はレティクルとミニマップに注目しやすいと解釈している。
    また、FPS 以外のジャンル（FIFA、StarCraft など）で熟練者がミニマップなどの重要な要素に視線を向けるという報告がある（Luo et al., 2025, p. 6・Table 3〔p. 7〕。含まれた7研究に FPS は無い）
- **書き方はすべて同じ形**：「ρ・向き（正／負）・先行研究と同じ向きか逆か」。内訳の3つは、先行研究の代わりに下部HUDまとめの向きと比べる
  - 先行研究の向き：Furukado & Hagiwara (2023) の群の差の向き（Table 2、p. 109）
  - **「傾向」の語は使わず、「向き」で統一する**（「傾向がある」は関係があると判定したように読めるため）
- **残りの3つ（ally_team_status・round_timer・enemy_team_status）は表と散布図だけ**（本文で ρ を取り上げて論じない）

### 4g. 人数による出し分け（2026-11-17 決定）
主解析に入った人数（参加者の数）で決める。副指標も同じ。平均注視時間は、AOI × 指標のセルごとに、値を計算できた人数で判定する（§8a）。

| 人数 | 出すもの |
|---|---|
| 4名以上 | ρ と向き |
| 3名 | ρ と向きに、「3名では関係がなくても必ず \|ρ\| ≥ 0.5 になる」を添える（同順位が無い場合） |
| 2名以下 | ρ を出さない。散布図だけを示し、「この人数では述べられない」と書く |

- 理由：2名の ρ は常に ±1（同順位が無い場合）。3名では |ρ| は 0.5 か 1 にしかならない

## 5. 床効果と、ρ が計算できないとき

- **案B（下部HUDの床効果）は採らない**（2026-11-09 決定）。PENDING_DECISIONS 1 の文案の基準（予備実験の全員が 0.5% 未満なら案B）を採用し、PL02 の下部HUDまとめが 1.53% で基準を満たさないため。下部HUDまとめは主要比較に残す（現在の名前：先行研究に対応する比較）
- 本実験で、ある AOI の値が**全員同じ**（例：全員 0）だと ρ が計算できない。そのときは：
  - その比較は ρ を出さず、記述（範囲・1件でも見た人の数）と散布図だけを報告する。比較の一覧（§3）からは外さず、「ρ を計算できない（全員同じ値）」と書く
  - ~~Holm のファミリーの数は 6（副次は 3）のまま~~ → 2026-11-16 に検定をやめたので不要
- 0 の人が多くても、全員同じでなければ ρ は計算する（同順位として扱う）。0 の人の数を併記する

## 8. 探索的な解析

### 8a. 副指標（2026-11-10 決定）
- 対象：§3 の9つの AOI（先行研究に対応する6つ＋下部HUDの内訳3つ）× 副指標3つ（注視数／分、平均注視時間、再訪回数／分）= 27 の順位相関
- ~~補正しない。p 値は参考として出すが、主張の根拠にしない。ρ と 95% 信頼区間を報告し~~ → **2026-11-16〜17 に変更**：p 値も信頼区間も出さない。**ρ と向き**を報告し（§4b・§4c、人数による出し分けは §4g）、「次の研究で確かめるべき仮説」として書く
  - 11/10 の理由（参考として残す）：27 個を補正しないと、関係が何もなくてもどれかが偶然「有意」になる確率は約 75%。27 個で Holm をかけると一番厳しい基準は 0.05/27 ≒ 0.0019 で、10名では |ρ| ≒ 0.87 が必要になり、ほぼ何も有意にならない。
    主指標を Gaze % と決めた時点で研究の問いは Gaze % で答える設計なので、副指標は Gaze % の結果を解釈する道具として使う（例：「高ランクほどミニマップの Gaze % が高く、1回の時間は同じで見に行く回数が多い」）
- **27 個すべてを表に載せる**（良さそうな結果だけを選んで出さない。補正しないことの前提）
- **再訪回数は1分あたり**（再訪回数 ÷ 有効分析時間〔分〕。分母は注視数／分と同じ `valid_time_sec`。参加者単位で回数と時間を足してから割る）。合計の回数は分析時間に比例し、分析時間（生存時間）はランクと関係しうるため、合計のままではランクの影響と区別できない（分析時間の下限は設けない：§1a）。合計の回数も参考として表に残す
- **平均注視時間は、その AOI の注視が0件の人では「値なし」**（0秒で埋めない）。AOI ごとに、計算に使えた人数を併記する。使えた人数が少ない AOI（上部HUD で起こりやすい）は ρ が不安定であることを明記する。§4g の出し分けは、このセルごとの人数で判定する
- 欠測 200 ms の感度分析（§6）で変わるのは副指標だけ。主解析と感度分析で副指標の結果が大きく変わるかも報告する
